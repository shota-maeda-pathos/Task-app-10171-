# 繰り返しタスクの重複防止・再試行

次回タスクの作成と元タスクの `recurrenceNextTaskId` 記録を同じ Firestore トランザクションで保存する。同時実行時は元タスクの更新競合により再評価され、生成済みなら追加しない。

完了保存後の生成失敗では完了状態・実績時間を維持し、通知に「次回生成を再試行」を表示する。再試行は元タスクの最新データを読み、生成だけを実行する。通知は画面内の移動や別の通知で消えず、再試行失敗後も残る。ページの再読み込みでは通知は保持されない。

従来の `recurrencePreviousTaskId` を持つ次回タスクが存在する場合はそれを採用する。複数存在する場合は追加せずエラーとする。生成済みの次回タスクを後から削除しても、元タスクの記録を維持して再生成しない。

繰り返し周期・見積・担当者・フォーカス初期値は従来どおり。締切未設定の場合は完了日時を基準にし、後日の再試行で次回締切がずれないようにする。

現在のクライアント間での重複防止であり、古いコードを開いたままの画面には適用されない。更新後は各画面を再読み込みする。Rules・Functions の変更は不要。実環境での複数画面・通信失敗テストは別途必要。
