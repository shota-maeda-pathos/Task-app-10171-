# 個人のタスク並び順

Homeの同じ列内の縦移動は、担当・作成権限に関係なく利用者本人の順序として保存する。列をまたぐ移動は従来の管理者・作成者・担当者チェックを維持する。子の並び替えもHome・My Tasks共通の個人順序を使う。

保存先は `members/{uid}/taskOrders/{scope}`。scopeは `root:未着手`、`root:進行中`、`root:完了`、または `children:{parentId}`。データは `taskIds: string[]` と `updatedAt: server timestamp`。読むのも書くのも有効な本人だけ。クライアントは本人のサブコレクションを購読する。共有タスクのorder・statusを更新しない。

別のPCでも同じアカウントなら順序が反映される。未保存の場合や新しいタスクは従来の共有順序が基準になる。削除されたIDは次の保存時に除外する。フィルター・グループで見えていないタスクの位置を保ち、最新の保存順序に表示部分の変更をマージする。手動ドラッグ後は優先度・締切ソートを解除する。

個人順序の取得中・取得エラー時はドラッグを無効にし、未取得の状態で他PCの保存順序を上書きしない。1つの保存順序は3000件まで。

ドラッグ直後は画面の並び順を即時更新し、Firebaseの購読が保存結果を受け取るまで維持する。保存に失敗した場合だけ保存済みの順序へ戻してエラーを表示する。同じ一覧への連続操作は操作した順に保存し、先の保存完了が後の操作の表示を上書きしない。
