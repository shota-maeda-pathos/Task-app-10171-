# 次回生成失敗の実画面テスト

`npm start` でローカル版を起動し、`http://localhost:4200/board?recurrenceTest=1` を開く。開発モード・ローカルホスト・専用クエリの3条件を満たす場合だけ検証パネルが表示される。公開サイトや本番ビルドでは利用できない。

ローカル版も接続先のFirebaseへ保存する。専用のテスト用タスクを使うこと。他の画面から同じタスクを同時に完了しないこと。

1. 「再試行テスト」などのタスクを作り、繰り返しを設定する。
2. 検証パネルでそのタスクを選び「一度だけ失敗をセット」を押す。
3. タスクを完了する。完了・実績保存は成功し、次回生成だけが失敗する。
4. 「次回生成を再試行」を押し、次回が1件だけ作られ、元タスクの完了・実績が維持されることを確認する。
5. 別のテスト用タスクで1～3を行い、再試行する前に画面を再読み込みする。
6. 「次回タスクが未生成です」に元タスクが表示され、その入口から再試行できることを確認する。

失敗設定はメモリ上にあり、一度失敗すると解除される。再読み込みでも解除される。検証後は通常の `/board` を開けばパネルが非表示になる。これは通信障害を意図的な例外で代替する検証であり、実際の通信障害・ブラウザ操作の確認を自動で済ませるものではない。
