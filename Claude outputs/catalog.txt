Task Flow + — 機能カタログ
=====================================

■ コンセプト
「チームの負荷を見える化し、最適な判断を促す」課題管理ツール。

一般的なカンバンボードの機能に加え、メンバーの稼働負荷をリアルタイムに
可視化・警告する仕組みを中核に据えている。タスクを割り振る際に「誰が
どれだけ余裕があるか」を数値で確認でき、過負荷時には代替メンバーの
提案まで行うことで、属人的な勘に頼らないチーム運営を実現する。

また、タスクに紐づいたチャット機能により、進捗の確認や相談を外部ツールに
切り替えることなくアプリ内で完結できる。会話が常にタスクと結びついている
ため情報が散逸せず、後から経緯を追うのも容易になる。

技術スタック: Angular 22 / Firebase Authentication / Cloud Firestore / Firebase Hosting


=====================================
1. カンバンボード
=====================================

  - 「未着手」「進行中」「完了」の3カラム表示
  - ドラッグ＆ドロップでステータスを直感的に変更
  - 各カラムからワンクリックでタスクを追加
  - タスクカードに情報を集約表示:
    作成日 / タスク名 / 見積もり時間 / 実績時間 / 担当者アバター /
    優先度（高・中・低）/ 締切日 / 依存ラベル / 停滞アラート


=====================================
2. 負荷管理 ← 本アプリの最大の特徴
=====================================

  【リアルタイム負荷モニター（サイドバー）】
  - メンバーごとの稼働負荷を % + プログレスバーで常時表示
  - 計算式: 未完了タスクの見積もり合計 ÷ 週間稼働可能時間
  - 3段階アラート: 正常（80%未満）/ 注意（80〜100%）/ 危険（100%超）
  - サイドバーは折りたたみ可能（ドットインジケーターに縮小）

  【タスク追加時の負荷プレビュー】
  - 新規タスクやサブタスクの追加フォーム内に、
    割り当て先メンバーの負荷変化をリアルタイムで表示
  - 親タスクのバッファ（子に未割当の時間）を加味した精密な計算

  【過負荷アラート＋代替メンバー提案】
  - 負荷100%超のメンバーに割り当てようとすると警告モーダルを表示
  - 最も負荷の低いメンバーをワンクリックで代替提案
  - 「それでも割り当てる」で強制割り当ても可能


=====================================
3. 親子タスク（エピック構造）
=====================================

  - 任意のタスクにサブタスクを追加 → 自動的にエピック表示に切り替わる
  - エピックの進捗率をサブタスクの完了割合から自動計算（プログレスバー表示）
  - サブタスクはチェックボックスでワンクリック完了切り替え
  - サブタスクの見積もり合計が親を超えた場合、親の見積もりを自動拡張
  - 親タスク削除時は子タスクも連動削除


=====================================
4. タスク依存関係（ブロッキング）
=====================================

  - タスク編集画面からチェックボックスで依存先タスクを複数選択可能
  - 依存先が未完了の間はステータスを進められない（ボタン無効化＋ドラッグ防止）
  - ブロック中のタスクに「○○ 待ち」ラベルを自動表示
  - ブロック先のタスクにもブロック数を表示


=====================================
5. 差し戻し（レビュー）フロー
=====================================

  - メンバーが進行中タスクを「差し戻し中」に変更し、理由をテキストで記入
  - マネージャーが承認（未着手に戻す）または却下（進行中に戻す）を判断
  - 差し戻し時に希望期日の変更も可能
  - 差し戻し中タスクは進行中カラムに専用スタイルで表示


=====================================
6. 停滞検出
=====================================

  - ステータスが3日以上変化していないタスクを自動検出
  - 該当タスクをカード上で視覚的にハイライト表示
  - 放置されたタスクの早期発見を促進


=====================================
7. タスク内チャット＋通知 ← チーム連携の要
=====================================

  タスクの進捗確認や相談をSlack等の外部ツールに切り替えることなく、
  タスクに紐づいたチャットでそのまま完結できる。
  「どのタスクについての会話か」が常に明確なため、
  情報の散逸を防ぎ、後から経緯を追うのも容易になる。

  【リアルタイムチャット】
  - タスクごとのコメントスレッド（サイドパネル表示）
  - Firestoreリアルタイムリスナーによる即時反映（送信と同時に相手に表示）
  - 自分のコメントの削除機能

  【自動通知システム】
  - コメント投稿時に担当者＋マネージャー全員へ自動通知（投稿者本人は除外）
  - ヘッダーの通知ベルに未読件数バッジ
  - 通知クリックで該当タスクのコメントパネルに直接遷移
  - 「すべて既読にする」一括操作 / 個別削除
  - 担当タスクへの新着コメント時にリアルタイムトースト通知


=====================================
8. 締切管理
=====================================

  - タスクごとに締切日を設定
  - 3段階の期限アラート: 期限切れ / 今日まで / 3日以内（色分け警告）
  - ダッシュボードのカレンダーで締切を一覧俯瞰（2か月表示・月送り対応）


=====================================
9. 検索・フィルタ・ソート
=====================================

  - タスク名によるインクリメンタル検索
  - 担当者フィルタ / 優先度フィルタ（高・中・低）
  - 並び替え: 優先度順 / 締切日順
  - フィルター条件の一括クリア


=====================================
10. ダッシュボード（分析画面）
=====================================

  - 全体進捗: 完了 / 総タスク数（% + プログレスバー）
  - 今週の完了タスク数
  - メンバーごとの統計:
    完了数 / 見積もり合計 / 実績合計 / 差分 / 見積もり精度(%) / 現在の負荷
  - 過去4週間の完了タスク推移グラフ（バーチャート）
  - 締切カレンダー（2か月分・タスクドット表示）
  - 自分の情報を先頭にハイライト表示


=====================================
11. 認証・権限
=====================================

  【認証】
  - Googleアカウントログイン / メール・パスワードログイン
  - 初回ログインでメンバー情報を自動作成（最初のユーザーは自動でマネージャー）
  - ユーザーごとのアバターカラー自動割り当て

  【権限管理】
  - Firestore Security Rulesによるサーバーサイド権限制御
  - マネージャー/メンバーの2ロール制
  - 設定画面はマネージャー専用（ルートガードでアクセス制御）
  - コメント削除は投稿者本人のみ / 通知は本人のみ閲覧可能


=====================================
12. 設定画面（マネージャー専用）
=====================================

  - メンバーの役割変更（マネージャー ↔ メンバー）
  - 週間稼働時間の変更
  - メンバーの削除（退出処理）


=====================================
13. リアルタイム同期
=====================================

  - Firestoreリアルタイムリスナーにより、複数ユーザーの操作が即座にUIへ反映
  - Angular Signalsとの統合で高効率な変更検知（ポーリング不要）


=====================================
14. UI / UX
=====================================

  - ダークモードベースのモダンデザイン
  - レスポンシブ対応（サイドバー折りたたみ）
  - 自分の情報を常に先頭にソート
  - モーダルダイアログによる確認UI（削除・完了・差し戻し・負荷警告）
  - トースト通知でリアルタイムフィードバック
  - 完了時に見積もり vs 実績の差分を即時フィードバック
