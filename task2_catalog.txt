SyncHub+ — 課題管理アプリケーション 機能カタログ
=====================================
■ 目的
=====================================

チーム開発において「誰が何をやっているか分からない」「特定の人に仕事が偏っている」
「タスクの相談をするのにSlackやメールに切り替えなければならない」といった課題は日常的に発生する。
SyncHub+は、これらの問題をひとつのアプリケーション内で解決する課題管理ツールである。

カンバンボードによるタスクの可視化に加え、メンバーの稼働負荷をリアルタイムに数値化・警告する仕組みを中核に据え、
「誰にどれだけ余裕があるか」を常に確認できる状態を作る。
さらに、タスクに紐づくチャット・通知・ファイル共有・活動履歴をアプリ内で完結させることで、
情報の散逸を防ぎ、チーム全員が同じ文脈の上で判断・行動できる環境を提供する。

=====================================
■ 機能
=====================================

------------------------------------------------------------------
1. カンバンボード — 直感的なタスク運用の中心
------------------------------------------------------------------

タスク管理の基本画面。3つのカラム（未着手・進行中・完了）でタスクの状態を一目で把握できる。

【ドラッグ＆ドロップによるステータス変更】
  タスクカードをカラム間にドラッグするだけでステータスを変更できる。
  マウス操作だけで完結するため、フォーム入力の手間がなく、直感的にタスクを進められる。

【カラム内のタスク並び替え】
  同じカラム内でもドラッグでタスクの表示順を自由に変更できる。
  チームの優先順位に合わせた柔軟な運用が可能。

【各カラムからのタスク追加】
  各カラムの下部にある入力フォームから、そのステータスのタスクを直接追加できる。
  タイトル・説明・担当者・見積もり時間・優先度・締切日・フォーカス設定をまとめて入力可能。

【グローバルタスク作成（FABボタン）】
  画面右下に常時表示されるフローティングアクションボタンにより、
  どの画面からでもワンクリックでタスク作成モーダルを開ける。
  担当者選択時には負荷率が表示され、過負荷時には代替メンバーを提案する。

【タスクカードの情報集約表示】
  1枚のカードに必要な情報を凝縮表示する。
  タスク名 / 作成者・作成日 / 見積もり時間 / 実績時間 / 担当者アバター /
  優先度（高🔴・中🟡・低🟢）/ 締切日と期限状態 / 依存ラベル / 停滞アラート /
  フォーカス状態（★マーク）/ ブロック数バッジ

【表示モードの切り替え】
  「詳細表示」と「コンパクト表示」を切り替えられる。
  タスク数が多い場合はコンパクト表示で全体を俯瞰し、
  詳細を確認したいときは詳細表示に切り替える使い分けが可能。

【タスク編集モーダル】
  カードをクリックすると編集モーダルが開き、
  タイトル・説明・担当者・見積もり時間・優先度・締切日・依存関係・
  フォーカス時間・予定週の設定を一画面で完結できる。

【タスクの完了処理】
  タスクを完了に移動する際、実績時間の入力を求めるモーダルが表示される。
  見積もりとの差分が即座にフィードバックされ、見積もり精度の振り返りに活用できる。

【アーカイブ機能】
  完了したタスクはアーカイブして非表示にできる。
  ボードをすっきり保ちながら、ダッシュボードからいつでも復元可能。

【検索・フィルタ・並び替え】
  - タスク名によるインクリメンタル検索
  - 担当者フィルタ / 優先度フィルタ / フォーカスフィルタ
  - 並び替え: 優先度順 / 締切日順
  - フィルター条件の一括クリア

【スイムレーン表示】
  タスクを担当者別・優先度別にグルーピングして表示できる。
  チーム全体の状況把握や、特定の切り口でのタスク確認に有効。

【一括操作】
  複数のタスクをチェックボックスで選択し、
  ステータス変更・担当者変更・削除をまとめて実行できる。
  スプリント終了時の繰り越し処理やメンバー異動時の再アサインなど、
  大量タスクの操作を効率化する。


------------------------------------------------------------------
2. 負荷管理 — チームの「余力」を数値で可視化
------------------------------------------------------------------

一般的なタスク管理ツールでは「誰がどれだけ忙しいか」は感覚に頼りがちである。
SyncHub+では、メンバーの稼働負荷を数値とバーで常時表示し、
タスクの割り振り判断を客観的なデータに基づいて行える。

【リアルタイム負荷モニター（サイドバー）】
  ボード画面のサイドバーに、メンバーごとの稼働負荷を%とプログレスバーで常時表示。
  計算式: フォーカスタスクの見積もり時間合計 ÷ 週間キャパシティ時間
  3段階の色分け: 正常（緑）/ 注意（黄: 80%以上）/ 危険（赤: 100%以上）

【タスク追加時の負荷プレビュー】
  新規タスクの追加フォームで担当者を選択すると、
  そのメンバーの現在の負荷率がリアルタイムに表示される。
  「このタスクを渡したら負荷がどうなるか」を事前に確認してからアサインできる。

【過負荷アラートと代替メンバー提案】
  負荷が100%を超えるメンバーにタスクを割り当てようとすると、
  警告モーダルが表示され、負荷の低いメンバーを代替候補として提案する。
  ワンクリックで代替メンバーに切り替えるか、理由があれば強制割り当ても可能。

【4週間負荷予測】
  今後4週間の負荷推移を週ごとのバーチャートで表示。
  フォーカス設定と締切日をもとに各週のタスク量を自動集計し、
  「来週は大丈夫だが再来週がパンクしそう」といった先の課題を事前に察知できる。
  サイドバー・マイタスク画面・ダッシュボードの3箇所で確認可能。

【サイドバーの幅調整・折りたたみ・メンバー順カスタマイズ】
  サイドバーはドラッグで幅を調整でき、折りたたんでボード領域を広く使うことも可能。
  メンバーの表示順もドラッグで自由に変更でき、順序はブラウザに保持される。

3. タスク構造 — 親子タスクと依存関係
------------------------------------------------------------------

大規模なタスクの分解と、タスク間の順序制約を管理する。
作業の粒度を細かくし、実行順序を明確にすることで、
チーム全体の作業フローを可視化する。

【親子タスク（エピック構造）】
  任意のタスクにサブタスクを追加すると、自動的にエピック表示に切り替わる。
  サブタスクのチェックボックスでワンクリック完了切り替え。
  親タスクの進捗率はサブタスクの完了割合から自動計算され、プログレスバーで表示。

【見積もり時間の自動集計】
  サブタスクの見積もり時間合計が親タスクを超えた場合、
  親の見積もりを自動的に拡張する。手動で整合性を取る手間がない。

【サブタスクの並び替え・締切バリデーション】
  サブタスク同士をドラッグで並び替え可能。
  サブタスクの締切日が親タスクの締切を超えていないかを自動で検証し、
  矛盾したスケジュールの設定を防止する。

【連動削除】
  親タスクを削除するとサブタスクも連動して削除される。

【依存関係（ブロッキング）】
  「Aが終わらないとBに着手できない」といった依存関係を設定可能。
  依存先が未完了の間はステータスを進められず、
  ボタン無効化とドラッグ防止により誤った順序での着手を防ぐ。
  ブロック中のタスクには「○○ 待ち」ラベル、
  ブロック元にはブロック数バッジが自動表示される。


------------------------------------------------------------------
4. ワークフロー管理 — レビューフローと停滞検出
------------------------------------------------------------------

タスクの品質チェックプロセスと、放置の早期発見を組み合わせ、
作業が滞りなく進むための仕組みを提供する。

【差し戻し（レビュー）フロー】
  メンバーが進行中タスクで「レビュー依頼」を実行すると、
  差し戻し理由をテキストで記入してマネージャーに送信。
  タスクは「差し戻し中」ステータスに変わり、進行中カラムに専用スタイルで表示。
  マネージャーは承認（未着手に戻す）または却下（進行中に戻す）を判断。
  通知ドロップダウンからも直接承認・却下操作が可能。
  メンバーは送信済みの依頼を自分で取り下げることもできる。

【停滞検出】
  ステータスが長期間変化していないタスクを自動検出し、
  カード上で視覚的にハイライト表示する。
  定期的なステータス確認を習慣化しなくても、放置されたタスクに気づける。


------------------------------------------------------------------
5. 週次フォーカスと繰り返しタスク — 計画と自動化
------------------------------------------------------------------

週単位の作業計画と、定例業務の自動化を組み合わせ、
「今週何をやるか」の明確化と定型作業の省力化を実現する。

【「今週やる」フォーカス】
  タスクに★マークを付けて「今週やる」として設定。
  フォーカス時間（今週そのタスクに充てる時間）を入力することで、
  週単位の作業計画を立てられる。

【予定週の設定】
  編集モーダルから今後4週間のどの週にタスクを予定するかを選択可能。
  「今週は無理だが来週やる」といった先の計画も立てられる。

【フォーカスフィルタ】
  ボード画面・マイタスク画面で「今週やる」タスクだけを絞り込み表示可能。

【繰り返しタスク】
  毎日・毎週・隔週・毎月の繰り返しルールをタスクに設定できる。
  タスクを完了すると、次回分のタスクが自動的に生成される。
  サブタスク構成もそのまま引き継がれるため、
  毎回同じ作業手順を再設定する必要がない。


------------------------------------------------------------------
6. タスク内コミュニケーション — チャット・メンション・ファイル共有
------------------------------------------------------------------

タスクの進捗確認や相談をSlack等の外部ツールに切り替えることなく、
タスクに紐づいたコミュニケーションでそのまま完結できる。
「どのタスクについての会話か」が常に明確なため、
情報の散逸を防ぎ、後から経緯を追うのも容易になる。

【リアルタイムチャット】
  タスクごとのコメントスレッドをサイドパネルで表示。
  Firestoreのリアルタイムリスナーにより、送信と同時に相手の画面にも反映される。
  Ctrl+Enterのキーボードショートカットで素早く送信可能。

【@メンション】
  コメント入力中に「@」を入力するとメンバー候補がサジェスト表示される。
  メンションされたメンバーには専用の通知が届くため、
  担当者でなくても関連するメンバーに注意を促すことができる。
  コメント内のメンション部分は視覚的にハイライトされ、誰に向けた発言かが一目で分かる。

【絵文字リアクション】
  コメントに6種類の絵文字（👍 ❤ 😂 🎉 👀 🙏）でリアクション可能。
  リアクション数と「誰がリアクションしたか」をツールチップで確認できる。
  テキストを打たなくても、既読確認や簡単な意思表示ができる。

【ファイル添付（最大10MB）】
  画像・PDF・Office文書・テキストファイルを添付でき、
  Firebase Storageにより1ファイルあたり最大10MBまで対応。
  画像はサムネイルプレビュー付きで表示され、クリックで拡大表示。
  仕様書や参考資料をタスクに直接紐づけて管理できる。

【活動履歴タブ】
  コメントパネルの「履歴」タブで、
  タスクの作成・ステータス変更・完了・担当者変更・優先度変更・
  締切変更・レビュー操作のすべてが時系列で記録される。
  「いつ誰が何をしたか」を後から正確に確認でき、チームの透明性を確保する。

【コメント・添付の削除】
  自分が投稿したコメント・添付ファイルは削除可能。
  他人のものは削除できないよう権限制御されている。


------------------------------------------------------------------
7. 通知システム — 見逃しを防ぐ自動アラート
------------------------------------------------------------------

タスクに関する重要な出来事を自動で通知し、
チーム内の情報伝達の抜け漏れを防止する。

【自動通知の対象】
  コメント投稿 / メンション / タスク作成 / レビュー依頼 / レビュー承認 /
  レビュー却下 / レビュー取り下げ / タスク完了
  上記の操作が行われると、担当者・マネージャーに自動通知が送信される。

【通知ベルとバッジ】
  ヘッダーの通知ベルアイコンに未読件数をバッジ表示。
  クリックでドロップダウンが開き、通知一覧を確認できる。

【ワンクリック遷移】
  通知をクリックすると、該当タスクのあるボード画面に自動遷移し、
  コメントパネルが開く。文脈をすぐに把握できる。

【リアルタイムトースト通知】
  自分が担当するタスクに新しいコメントが投稿されると、
  画面上にトースト通知がリアルタイムで表示される。

【通知内レビュー操作】
  レビュー依頼の通知にはそのまま承認・却下ボタンが付いており、
  通知ドロップダウンから直接レビュー対応が可能。

【一括既読・個別削除】
  「すべて既読にする」ボタンで一括処理が可能。
  不要な通知は個別に削除できる。


------------------------------------------------------------------
8. マイタスク画面 — 個人の作業を集中管理
------------------------------------------------------------------

自分に割り当てられたタスクだけを一覧で確認できる専用画面。
ボード全体を見渡す必要がなく、今日やるべきことに集中できる。

【サマリーカード】
  画面上部に4つの統計カードを表示。
  未完了タスク数 / 今日が期限のタスク数 / 期限切れタスク数 /
  今週の負荷率（タスク数・時間の内訳付き）

【進捗バーと4週間負荷予測】
  自分のタスク全体の完了率をプログレスバーで表示。
  今後4週間の週別負荷をバーチャートで確認でき、先のスケジュール感を把握できる。

【タスク一覧（未完了 / 完了済みタブ）】
  タスクをカード形式で一覧表示。カードをクリックすると詳細が展開され、
  説明・ステータス・締切・見積もり/実績時間・サブタスクを確認できる。
  サブタスクのチェック切り替え・ドラッグ並び替え・ステータス操作もこの画面で完結。

【並び替え・検索・フィルタ】
  期限グループ（期限切れ / 今日 / これから / 期限なし）/ 優先度順 / 期限順 / ステータス順。
  タスク名検索と「今週やるのみ」フィルタに対応。

【締切カレンダー】
  自分のタスクを月別カレンダーに表示。
  タスクチップをドラッグして別の日に移動するだけで締切日を変更できる。
  モバイルでは1か月、デスクトップでは2か月を同時表示。


------------------------------------------------------------------
9. ダッシュボード — チーム全体の状況を分析
------------------------------------------------------------------

チーム全体の進捗・負荷・実績を俯瞰する分析画面。
マネージャーがチームの状態を把握し、的確な判断を下すための情報を集約する。

【全体進捗】
  完了タスク数 / 総タスク数の比率をプログレスバーと%で表示。
  直近1週間の完了タスク数も合わせて確認できる。

【メンバー別負荷モニターと4週間負荷予測】
  メンバーごとの現在の負荷と、今後4週間の負荷推移をバーチャートで表示。
  自分の負荷を先頭に表示し、他メンバーは折りたたみ可能。
  メンバー行をクリックするとボード画面に遷移し、表示順はドラッグでカスタマイズ可能。

【締切カレンダー】
  チーム全員のタスク（完了済みを除く）を月別カレンダーに表示。
  ドラッグで締切変更、クリックで詳細確認が可能。

【完了タスク推移グラフ】
  過去4週間の完了タスク数を棒グラフで表示。
  チームの生産性の傾向を視覚的に確認できる。

【見積もり精度分析】
  メンバーごとに見積もり合計・実績合計・差分・見積もり精度(%)を表示。
  個人の見積もり傾向を把握し、今後の改善に活用できる。

【アーカイブ管理】
  アーカイブ済みタスクをカード型リストで一覧表示。
  担当者アバター・タスク名・完了日・見積もり/実績時間を1行に集約し、
  実績が見積もりを超過したタスクは赤色バッジで警告表示する。
  セクションはアコーディオンで折りたたみ可能で、件数バッジを常時表示。
  復元・削除ボタンはマネージャー・担当者・作成者のみに表示される権限制御付き。
  CSVエクスポートにも対応し、Home画面と同じカラム構成で出力できる。


------------------------------------------------------------------
10. タスクテンプレート — 定型作業のワンクリック作成
------------------------------------------------------------------

繰り返し発生する定型タスクをテンプレートとして保存し、
次回以降はワンクリックで入力フォームに反映できる。

【テンプレートの作成と管理】
  設定画面からテンプレートを作成・編集・削除できる。
  テンプレート名・タスクタイトル・説明・見積もり時間・優先度に加え、
  サブタスク構成（タイトル・見積もり時間）もテンプレートに含められる。

【既存タスクからのテンプレート保存】
  編集モーダルの「テンプレ保存」ボタンで、
  現在のタスク（サブタスク構成を含む）をそのままテンプレートとして保存できる。

【テンプレートからのタスク作成】
  ボードの各カラムやFABモーダルからテンプレートを選択すると、
  フォームにテンプレートの内容が自動で反映される。
  必要に応じて内容を調整してから作成できるため、柔軟な運用が可能。

【プライバシー】
  テンプレートは作成者本人にのみ表示される。
  Firestoreセキュリティルールにより、他ユーザーからのアクセスを防止。


------------------------------------------------------------------
11. 締切管理 — 期限意識の定着
------------------------------------------------------------------

【タスクごとの締切設定】
  タスクの作成・編集時に締切日を設定できる。

【3段階の期限アラート】
  期限切れ（赤）/ 今日が期限（オレンジ）/ 3日以内（黄色）の3段階で色分け警告。
  カード上に表示されるため、一目で緊急度が分かる。

【カレンダー表示とドラッグ操作による締切変更】
  マイタスク画面とダッシュボードに月別カレンダーを搭載。
  締切日を俯瞰的に確認でき、タスクチップをドラッグするだけで締切日を直接変更可能。
  モバイルでは1か月、デスクトップでは2か月を同時表示し、月送りナビゲーションに対応。


------------------------------------------------------------------
12. 認証・権限・設定 — セキュアなチーム運用
------------------------------------------------------------------

【認証方式】
  Googleアカウントログインとメール・パスワードログインの2方式に対応。
  初回ログイン時にメンバー情報を自動作成し、
  最初のユーザーには自動的にマネージャー権限を付与。

【2ロール制による権限管理】
  - マネージャー: 全タスクの管理、メンバーの追加・編集・削除、レビュー承認・却下
  - メンバー: タスクの閲覧・更新、レビュー依頼

【Firestoreセキュリティルールによるサーバーサイド制御】
  クライアント側の表示制御だけでなく、サーバー側でもデータアクセスを制御。
  コメント削除は投稿者本人のみ / 通知は本人のみ閲覧 / テンプレートは作成者のみ /
  メンバー削除はマネージャーのみ。ルートガードによるURL直接アクセスの防止も実装。

【プロフィール設定】
  表示名と週間キャパシティ時間を変更可能。

【テーマカラー設定】
  9種類のカラーテーマ（Default / Ocean Breeze / Sunset Warm / Lavender Night /
  Midnight Blue / Forest / Rose / Noir / Candy Pop）から選択可能。
  プレビューカード付きで視覚的に選択でき、異なるデバイスでも同じテーマが適用される。

【メンバー管理（マネージャー専用）】
  メンバーの役割変更・週間キャパシティ変更・削除・表示順のドラッグ並び替えが可能。


------------------------------------------------------------------
13. データエクスポート — 外部での活用と報告
------------------------------------------------------------------

タスクデータをCSV形式でエクスポートし、
ExcelやGoogleスプレッドシートでの分析・報告書作成に活用できる。

【CSVエクスポート】
  タスク一覧をCSVファイルとしてダウンロードできる。
  タスク名・ステータス・担当者・優先度・見積もり時間・実績時間・
  締切日・作成日・完了日を含む、管理に必要なすべてのフィールドを出力。

【フィルタ連動】
  現在適用中のフィルタ条件に基づいた絞り込みエクスポートが可能。
  「進行中のタスクだけ」「特定の担当者のタスクだけ」といった
  目的に応じたデータ抽出ができる。

【ダッシュボードからのチーム統計エクスポート】
  メンバーごとの見積もり精度・負荷状況・完了タスク推移など、
  ダッシュボードの分析データもCSVで出力可能。
  週次・月次の報告書作成を効率化する。


------------------------------------------------------------------
14. UI / UX — 快適な操作体験
------------------------------------------------------------------

【リアルタイム同期】
  Firestoreのリアルタイムリスナーにより、複数ユーザーの操作が即座にUIへ反映。
  タスクの追加・編集・ステータス変更・コメント投稿がリアルタイムで全員の画面に同期。
  ページのリロードやポーリングは不要で、Angular Signalsとの統合により
  変更のあった部分だけを効率的に再描画する。

【レスポンシブデザイン】
  デスクトップとモバイルの両方で快適に操作できるよう最適化。
  モバイルでは画面下部のボトムナビゲーションバー、横向き時の注意表示、
  スイムレーンの折りたたみ表示など、タッチ操作に最適化されたUIを提供。
  デスクトップではサイドバー・コメントパネルの幅調整や2か月カレンダー同時表示に対応。

【自動スクロール】
  タスクを新規追加した際、追加されたタスクが画面外にある場合は
  自動的にスクロールして表示位置まで移動する。
  通知クリック時にも該当タスクまで自動スクロールし、コメントパネルを開く。

【モーダルダイアログによる確認UI】
  削除・完了・差し戻し・負荷警告など、重要な操作には確認モーダルを表示。
  誤操作を防止しつつ、必要な情報入力を一画面で完結させる。

【トースト通知】
  操作の結果やリアルタイムイベントを画面上のトースト通知で即座にフィードバック。

=====================================
■ 制約条件
=====================================

- 本アプリケーションはFirebaseをバックエンドとして使用しており、
  同一Firebaseプロジェクト内のチームでの利用を想定している。
- ファイル添付のサイズ上限は1ファイルあたり10MBである。
- 対応ブラウザはChrome・Edge・Safari・Firefoxの最新版である。
- タスクの依存関係は循環を自動検出しないため、ユーザーが注意する必要がある。
